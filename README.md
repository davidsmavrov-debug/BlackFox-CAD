# BlackFox-CAD

Free and open-source CAD and engineering tools.

## IngeTrazo exporters

- [BlackFox SKP Exporter v1.0.0](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/skp-exporter-v1.0.0) opens, imports, and exports SketchUp models.
- [BlackFox CAD Exporter v1.0.1](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/exporter-v1.0.1) exports 3D CAD geometry to DXF and DWG.
