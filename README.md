# BlackFox-CAD

Free and open-source CAD and engineering tools.

## IngeTrazo extensions

- [BlackFox SKP Exporter v1.0.0](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/skp-exporter-v1.0.0) opens, imports, and exports SketchUp models.
- [BlackFox CAD Exporter v1.0.1](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/exporter-v1.0.1) exports 3D CAD geometry to DXF and DWG.

- [BlackFox 3D Inspector v1.2.0](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/inspector-v1.2.0) inspects models and extension APIs in a read-only report you can copy or export to TXT.
- [BlackFox Catenary v1.0.0](https://github.com/davidsmavrov-debug/BlackFox-CAD/releases/tag/catenary-v1.0.0) creates gravity-aligned catenary curves between two 3D points.
